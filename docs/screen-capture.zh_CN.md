# 实机屏幕截图

2.6.7 候选版新增 USB 命令 `FAP_SCREENSHOT_V1\n`，返回协议头以及严格
153,600 字节的 RGB565LE 像素。画面为 240 × 320，竖版 3:4。这是工牌实际
渲染画面的数字截图，不是外壳照片，也不是电脑端模拟图。

截图复用现有分块显示缓冲，在圆角遮罩之后、屏幕字节交换之前提取数据。
持有 LVGL 锁时执行一次完整重绘，按照从上到下的顺序传输，不额外分配整屏
帧缓冲。USB 写入总超时为三秒。截图期间界面更新暂缓，建议在静止页面截图，
避免正在播放音频或对话时截图。

命令不会跳转页面、唤醒屏幕、重启设备或修改保存的设置。息屏时返回
`FAP_SCREENSHOT_ERROR screen_unavailable`，需先用物理按键唤醒。
截图请求仅接受 USB 命令，不向热点配置接口开放。

串口必须在打开前设置 DTR、RTS 为非有效状态。截图前断开配置页的串口连接。
电脑端必须校验协议头、完整字节数和尺寸，丢弃不完整传输，不得把超时结果
保存为看似成功的图片。

发布素材保留原生分辨率 PNG，检查个人资料及秘密信息后再复制到公开素材目录。
封面使用当前首页；通过正常硬件按键选择小程序页面。不得把电脑预览标为实机
截图。固件安装和截图是独立操作；截图本身不会刷写或重启设备。

## 候选版验证

主机分块测试覆盖像素字节顺序、行填充、缺失帧、非法或乱序分块、传输失败及
重新截图。经明确授权安装后，仍需实机验证截图、拔线恢复及对播放的影响。
候选版编译通过不代表已经取得实机截图。
