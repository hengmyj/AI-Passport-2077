# Assets

See [Zen Muyu asset provenance](muyu-assets.md) for the application background, fonts, sound synthesis, licenses and regeneration steps.

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

## Images

Store reusable source images and generated display assets in `images/`.

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

## Voice Keychain assets

`audio/voice-keychain/` contains 726 raw Opus clips in 24 packs from Shinku-Chen/ai-passport, feature/voice-keychain, commit `71c45cabc1b2f3b73b4929d71cafd926ccbb11f5`. Audio is copied without re-encoding: 16 kHz mono, little-endian 2-byte packet lengths. `SOURCE.txt` records provenance. Upstream code is MIT; media rights are separate and are not relicensed as MIT. `tools/build_voice_pack.py` generates partition images and the catalog. Noto Sans SC 14px supplies 1071 glyphs via `tools/generate_voice_font.py`; see `fonts/OFL.txt`.

1.9.1 retains one clip per user-approved group (46 groups). `audio/voice-keychain/selection.json` records retained and removed items; retained files are not re-encoded.

- [City Radio integration, MIT source and themed previews](../docs/leo-radio.md): provenance in `assets/radio/`; production LVGL renders in `assets/images/leo-radio/`.

XiaoZhi source license and notice: `xiaozhi/LICENSE`, `xiaozhi/NOTICE`. The caption font uses the existing Noto Sans SC OFL font; generated by `tools/generate_xiaozhi_font.py`. See [integration details](../docs/xiaozhi.md).

[Portrait homepage fonts and offline embedding](../docs/portrait-home.md): Orbitron and Caveat, SIL OFL; source TTF, Latin WOFF2 subsets and license texts in `fonts/`.

Shared 14px UI font: `fonts/ui14-characters.txt` retains legacy coverage; `tools/generate_shared_fonts.py` generates `main/font_ui_14.c` for three UI fonts. It retains Noto Sans SC (SIL OFL) and the original glyph pixels/metrics. Caption additions are checked against the source font cmap to avoid embedding missing-glyph placeholders.

XiaoZhi face: original artwork created for this project, under the repository MIT license, in `images/xiaozhi-face/*.svg`. `tools/generate_face_assets.py` converts the limited SVG vocabulary offline to themed A8 masks in `main/xiaozhi_face_assets.c`. See [expressions and clock](../docs/face-clock.md).

King of the Road SVGs (images/xiaozhi-face/round_*.svg) are redrawn from a character reference supplied by the user. The reference photo itself is not included in the repository or release archive.

Cyber Yao classical text and calculation rules derive from CyberYAO commit
`3c4780feea04737e6e59b6e1849e591710e6656c`. Its MIT notice is in
[cyberyao/LICENSE](cyberyao/LICENSE); the adapted text table is in
`main/yao_text_data.c`. No upstream media or font assets are redistributed.

The Cyber Yao `interpret-request.ogg` is project-generated synthetic Mandarin speech, not an upstream recording. It asks XiaoZhi to query and interpret the retained hexagram. `main/assets/yao_request.h` contains its 60 ms Opus packets for direct uplink; it contains no personal recordings.

Company names use `fonts/NotoSansSC-brand-latin.woff2` (Noto Sans SC, SIL OFL 1.1, `fonts/OFL.txt`), an ASCII/ellipsis subset at weight 700. Generate with `tools/generate_brand_font.py <NotoSansSC.ttf>`. The offline editor embeds it as BadgeBrand; headings and signatures retain their existing fonts.
