# NFC 使用说明（2.4.8）

配置页仅保留安卓手机操作说明，移除网址输入、传递二维码、Web NFC 读写按钮
及 NFC JavaScript。NTAG213 独立于主控，USB 或热点保存工牌资料不会写入 NFC。
一块标签的网址由全部五张身份牌共用。

开启手机 NFC，打开 NFC 写入应用（例如 NXP TagWriter），添加网址记录，填写
目标网站，将手机贴近工牌直到写入成功。写入替换原标签内容；保留可写状态以便
以后修改。退出应用，移开手机后再次碰一碰，按手机提示验证打开的网址。

页面中的网址只是示例，不是标签回读结果，也不表示已写入。公网网页需要手机
联网；热点配置页需先连接工牌热点。修改 NFC 内容无需更新固件。2.4.8 只是同步
更新内置热点帮助页面，并不对 NFC 芯片进行编程。
