# 首次配置与返回导航 — 1.9.0

当前跳转规则（2.2.0）：首页上键直接打开小程序列表，首次配置页也适用；列表记住首页或员工终端作为返回上一级。
工牌资料页直接显示热点引导，OK 在本页开关热点。以下保留 1.9.0 原始行为和验证记录。

五个位置都没有已保存的工牌时，首页显示配置引导，并自动请求开启带密码的配置热点。已有工牌的设备仍直接展示工牌。清除最后一张已配置工牌后，也会再次进入引导，不删除其他设置。

引导包含热点名称与密码、`http://192.168.4.1`、保存和显示工牌的步骤，并提醒手机提示“无互联网”时保持连接。下键进入菜单，上键进入设置；热点关闭或启动失败时，OK 可重新开启。首次配置期间暂停十分钟空闲关闭规则，仍允许手动关闭热点。保存第一张工牌后恢复普通空闲规则，重新计时十分钟，保持当前配置连接。

从系统设置或工牌资料进入网络引导，也会按需打开热点。热点已开启时不会更换密码或断开客户端。浏览器中保存所需工牌；如果编辑的不是当前显示位置，保存后再点 **显示这张工牌**。

## 返回选择

非首页页面长按 OK，打开统一的返回选项：

1. 返回上一级
2. 回到首页
3. 继续当前页面

上下选择，OK 确认，再次长按 OK 取消。设置页记住自己是由首页还是员工终端打开；网络引导记住自己来自设置还是工牌资料。快捷二维码保留原有的短按返回操作。两个游戏也支持此菜单：“返回上一级”遵循语音游戏内部分类/音量页面层级；“回到首页”会先停止游戏任务，再销毁游戏页面。停止超时保留游戏，允许重试。

## 工牌留白

姓名图像移到屏幕 `(20,116)`，部门移到 `(20,158)`，职位移到 `(20,184)`。资料区从 `(14,102)` 开始，姓名图像之前有 14 像素顶部留白，左侧有 6 像素留白。RGB565 裁剪来源及存储格式不变，已保存的工牌立即使用新间距。浏览器预览采用同一组区域参数，Node 测试会逐项核对。
